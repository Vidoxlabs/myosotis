# Myosotis charter

## Mission

Build the memory fabric an agent can be trusted with. Myosotis holds the contracts for memory where the answer to "may this be kept" is a governed decision, and the answer to "forget this" is a structural guarantee.

The name is the point: the flower's ordinary name is forget-me-not, and this system's hardest promise is the opposite direction done right — when the owner says forget, it is forgotten everywhere, structurally, and the fabric can prove its projections are not lying about what they remember.

## Principles

1. **Consent precedes keep.** Personal memory enters the store only under a live consent record naming the scope. There is no ambient consent, no inferred consent, and no consent-by-default because the conversation went well.
2. **Classes stay distinguishable.** Organizational knowledge, consented personal memory, active-thread working context, and unconfirmed observations are four different things. The fabric never silently promotes one to another.
3. **Unconfirmed is not established.** An observation that has not been confirmed stays marked unconfirmed and is never presented as knowledge.
4. **Forget is structural.** A real forget removes the record and bumps the store epoch. Every projection stamped before the bump is stale; stale projections fail closed and must be rebuilt from the store. Bypass and rebuild — never resurrect.
5. **Unknown is declared.** A forget that matches no record is reported as unknown. Silence is not an acceptable answer to a forget.
6. **Projection until verified.** Caches, indexes, and summaries are projections. The store is the authority. A projection's claim is only as good as its epoch stamp.

## Non-goals

- **Not a chat log.** Reading evidence or posting a message creates no memory. Conversation text is not memory by default.
- **Not retrieval.** Finding and ranking context is capillary's province. Myosotis is what is permitted to be kept and what must be forgotten; capillary is what is fetched and how its provenance is carried.
- **No ambient inference.** The fabric does not guess what a person "probably wants remembered." Memory is created by declared acts — a keep, a note, a save — not by vibes.
